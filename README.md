# 🥖 Padaria do Seu Zé — Website Institucional & Sistema de Pedidos

Um site institucional e responsivo desenvolvido para simular a presença online, catálogo de produtos e formulário de atendimento de uma padaria local.

> 📌 **Projeto de Aprendizado:** Desenvolvido para consolidar conceitos fundamentais de desenvolvimento Web Front-end, manipulação de formulários e estrutura semântica.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da aplicação (`<header>`, `<nav>`, `<main>`, `<footer>`, formulários e mídias).
* **CSS3:** Estilização visual, tipografia e layout.
* **JavaScript:** Interatividade da interface e manipulação do DOM.
* **Project IDX / Firebase Studio:** Ambiente de desenvolvimento e prototipagem.

---

## ⚙️ Funcionalidades do Projeto

- [x] **Catálogo Interativo:** Exibição de produtos categorizados (Pães, Doces, Salgados e Bebidas).
- [x] **Formulário de Contato & Feedback:** Captura de dados do usuário com campos validados (Nome, E-mail, Telefone e Assunto).
- [x] **Mídia Integrada:** Seção institucional com exibição de vídeos do ambiente e experiência da padaria.
- [x] **Multi-páginas:** Navegação entre telas de cadastro, contato, pedidos e histórico (`index`, `cadastro`, `contato`, `feedback`, `pedidospp`).

---

## 💡 Aprendizados e Conceitos Aplicados

Durante o desenvolvimento deste projeto, foram praticados:
1. Semântica HTML para melhor acessibilidade e estrutura de código.
2. Organização e modularização de arquivos (`/CSS`, `/JS`, `/IMAGES`, `/VIDEOS`).
3. Construção de formulários funcionais no Front-end com múltiplos tipos de entrada (`inputs`, `selects`, `textareas`).
